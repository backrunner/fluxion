Fluxion is a native Mac download manager for HTTP, HTTPS, BitTorrent, FTP and SFTP. Task history and settings are managed locally.

## Choose a guide

1. [Add your first download](/docs/downloading).
2. [Manage tasks and the trash](/docs/tasks).
3. [Understand protocols and connection rules](/docs/protocols).
4. [Choose files and folders](/docs/permissions).
5. [Resolve common issues](/docs/troubleshooting).

The interface supports English, Simplified Chinese, Japanese and Korean, with system, light and dark appearance modes. This documentation is available in English and Simplified Chinese.

Fluxion is still in development. See [release status](/download) before looking for an App Store download.
