## 添加任务

1. 在下载工作区选择**新建**。
2. 粘贴 HTTP、HTTPS、FTP 或 SFTP 链接、磁力链接，或选择本地 `.torrent` 文件。
3. 选择下载目录。使用沙盒构建时，请通过目录选择器授权访问“下载”目录以外的位置。
4. 检查文件名与可用的高级设置，然后创建任务。

磁力链接可先解析文件列表，再选择要下载的文件。解析需要可访问的节点或 Tracker，可能需要等待。写入前会检查远程来源提供的文件名与路径。

## 高级设置

HTTP 传输可设置自定义请求头、Cookie、Referer 与 User-Agent。凭据与签名链接可能授予私人内容访问权限：请仅使用可信来源，勿在公开反馈中包含这些值。

FTP 与 SFTP 可使用用户名和密码。SFTP 也可通过文件选择器选择私钥，并填写可选口令。BitTorrent 可选择文件、添加 Tracker、开启做种及设置分享率限制。

## 续传与限速

HTTP 续传取决于 Range 支持和来源校验信息；远程资源变化时可能需要重新下载。FTP 续传需要服务器支持 REST。SFTP 可根据本地部分文件续传远程来源。

可以为单个任务或在设置中配置下载、上传限速。设置表单的单位为 **KB/s**，留空表示不配置限速。实际速度仍受服务器与协议条件影响。

## 找到文件

任务完成后，使用文件夹操作在 Finder 中显示下载文件。“已完成”记录的是传输完成状态；在 Fluxion 外移动或删除文件，可能使保存的位置失效。
