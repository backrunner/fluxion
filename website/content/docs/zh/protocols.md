## 支持的协议

| 协议 | 当前行为 |
| --- | --- |
| HTTP / HTTPS | 重定向与 Range 探测、分段传输、续传检查、重试和单流回退 |
| BitTorrent | 种子与磁力链接、Tracker/DHT、文件选择、片段与文件状态、做种及限速 |
| FTP | 文件传输，以及服务器支持时的部分文件续传 |
| SFTP | 密码或私钥认证、部分文件续传及保存的主机密钥检查 |
| FTPS | 不支持，会明确拒绝 |

## BitTorrent 连接规则

设置提供 IP 允许与拒绝列表、屏蔽的客户端名称及 Peer ID 前缀。每行填写一条规则。IP 规则支持单个地址或 CIDR 网段。

允许规则优先于拒绝规则。**允许列表非空时，允许列表以外的其他节点会被拒绝。** IPv4 映射的 IPv6 地址会按对应 IPv4 规则检查。客户端名称匹配不区分大小写，Peer ID 前缀匹配区分大小写。

规则适用于新启动或重新启动的任务及磁力预览，正在运行的任务保留当前连接规则。客户端名称与 Peer ID 属于节点自报信息，或根据节点 ID 推断，可以被伪造。这些规则不提供身份认证或匿名服务。

暂未实现快速断连行为屏蔽，请勿将其作为防滥用功能依赖。路由器端口转发与 NAT 状态会影响入站连接；当前不承诺自动 UPnP 配置。

## 分享与内容权利

BitTorrent 下载过程中可能上传片段。仅在开启做种时，完成后才会按分享限制继续上传。请仅下载与分享你有权访问和分发的内容。

## SFTP 主机密钥

首次连接会保存观察到的主机指纹，即首次使用信任（TOFU）。后续连接会拒绝变化的密钥。这可防止未经预期的变化，但无法独立证明首次连接服务器的身份。密钥变化时，请先通过可信渠道向服务器运营者核实新指纹。Fluxion 不会静默替换保存的密钥。

## 代理与加密

系统代理行为取决于协议与平台设置，不保证匿名。FTP 不加密数据与凭据。敏感传输请使用 HTTPS 或 SFTP。私有 Tracker 链接与磁力参数可能携带凭据，请勿将其加入公开反馈。
