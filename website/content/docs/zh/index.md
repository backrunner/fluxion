Fluxion 是原生 Mac 下载管理器，支持 HTTP、HTTPS、BitTorrent、FTP 与 SFTP。任务历史与设置在本机管理。

## 选择一份指南

1. [添加第一个下载](/docs/zh/downloading)。
2. [管理任务与废纸篓](/docs/zh/tasks)。
3. [了解协议与连接规则](/docs/zh/protocols)。
4. [选择文件与目录](/docs/zh/permissions)。
5. [排查常见问题](/docs/zh/troubleshooting)。

应用界面支持英文、简体中文、日文与韩文，提供跟随系统、浅色与深色外观。本网站文档提供英文与简体中文。

Fluxion 仍在开发中。寻找 App Store 下载前，请先查看[发行状态](/zh/download)。
