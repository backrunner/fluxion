## HTTP 无法续传

检查来源链接是否过期、远程资源是否变化，以及服务器是否支持字节范围请求。认证可能需要更新 Cookie 或请求头。拒绝分段请求的服务器可能需要单流传输。应先确认来源有效，再重试，避免盲目修改本地部分文件。

## FTP 或 SFTP 失败

确认主机名、端口、用户名及认证方式。FTP 不等于 FTPS，FTPS 链接当前会被明确拒绝。FTP 续传需要服务器支持。SFTP 在首次连接后要求主机密钥匹配；遇到密钥变化错误时，应联系服务器运营者核实，不应忽略。

网络等待停滞时，可暂停任务。网络操作有时间上限，并尽可能保留本地部分数据。重复重试无法使已停止的服务器恢复可用。

## 磁力链接没有文件列表，或种子没有节点

解析元数据需要可访问的节点或 Tracker。检查 Tracker 列表、网络访问及连接规则。允许列表非空时，会拒绝列表以外的节点。屏蔽客户端名称与 Peer ID 前缀也可能排除可用节点。运行中任务需重新启动，新的规则才会生效。

种子内容必须匹配片段哈希。Fluxion 引擎会校验片段，损坏的已有数据可能需要重新下载。缺少可用做种节点，可能意味着无法获得缺失片段。

## 下载目录不可用

重新连接磁盘，检查权限与可用空间。沙盒构建请通过选择器重新选择目录。查看[文件与权限](/docs/zh/permissions)。

## 批量操作仅部分成功

每个任务独立处理。请阅读失败报告，检查失败任务，同时确认其他任务是否已完成所请求的操作。

## 报告问题

查看[支持页面](/zh/support)。请提供可复现步骤与脱敏错误文字，勿包含密码、签名链接、私有 Tracker 地址或私钥。OnFire 私密支持渠道正在准备，当前尚未开放。
